Meja Resepsionis — Terbuka 24 Jam

Tulis satu pesan. Ia akan mendarat di channel Telegram kami dalam hitungan detik.

KabarKita adalah meja resepsionis digital — sebuah formulir terbuka yang meneruskan pesan Anda langsung ke channel Telegram publik kami. Tidak ada akun yang perlu dibuat. Tidak ada email yang perlu diverifikasi. Tidak ada aplikasi yang perlu dipasang.

Anda cukup menulis pesan, menekan satu tombol, dan sebuah bot di server kami akan mengantarkannya ke channel @kabar_kita. Pesan Anda mendukung format tebal, miring, kode, dan kutipan — seperti menulis di editor teks biasa.

  • Tujuan Channel @kabar_kita
  • Cara kirim Satu tombol, tanpa akun
  • Data disimpan Tidak ada
  • Waktu tayang Maks. 1×24 jam

— Cara Kerja

Tiga langkah, selesai.

Tidak ada langkah tersembunyi, tidak ada verifikasi. Dari klik pertama sampai pesan muncul di channel, semuanya transparan.

01

Klik tombol di bawah

Sebuah kartu akan muncul dari bawah layar. Hanya ada satu kolom: pesan Anda. Tidak ada nama, tidak ada email.

02

Tulis & format

Gunakan toolbar untuk menebalkan, memiringkan, atau mengutip bagian tertentu. Karakter maksimal 4096 — sama seperti batas Telegram.

03

Bot meneruskan

Setelah ditekan kirim, serverless function kami langsung meneruskan pesan Anda ke channel melalui Telegram Bot API.

— Di Balik Layar

Ini yang sebenarnya terjadi.

Setiap kali Anda menekan tombol kirim, potongan kode di bawah ini dieksekusi di serverless function kami. Tidak ada database. Tidak ada file log. Pesan Anda lewat, diteruskan, lalu selesai.

// Terima pesan dari form dan teruskan ke Telegram export default async function handler(req, res) { const raw = req.body?.message || '' if (!raw.trim() || raw.length > 4096) { return res.status(400).json({ ok: false }) } // Escape HTML, lalu ubah markdown jadi tag Telegram const safe = formatForTelegram(raw) await fetch( `https://api.telegram.org/bot${process.env.TELEGRAM_BOT_TOKEN}/sendMessage`, { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ chat_id: process.env.TELEGRAM_CHAT_ID, text: safe, parse_mode: 'HTML' }) } ) return res.status(200).json({ ok: true }) }
